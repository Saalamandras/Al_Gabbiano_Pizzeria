# Al Gabbiano Pizzeria

A React-based multi-page website for [Al Gabbiano Pizzeria](https://github.com/Saalamandras/Al_Gabbiano_Pizzeria), showcasing a modern and responsive pizza menu. Built as a portfolio project to practice React, routing, and design.

## Features
- **Multi-page layout**: Home, Menu, About, Contact
- **Interactive navigation menu** (sticky at the top)
- **Responsive grid of pizza cards** with images, ingredients, prices, and placeholder "Order Now" buttons
- **Mobile-friendly design**
- **Logo and pizza images** included

## How to Run Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Saalamandras/Al_Gabbiano_Pizzeria.git
   cd Al_Gabbiano_Pizzeria
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm start
   ```

4. Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
